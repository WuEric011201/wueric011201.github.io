An on-going hybrid delay + reverb pedal.

## Topology

- **PT2399** delay chip for the delay path
- **Belton Brick** (Accutronics BTDR-2H Digi-Log) reverb module for the reverb tail
- Buffered send and return around each stage, mixed inside a single enclosure
