A standalone overdrive pedal built for my friend Allan. Original post: [Overdrive Guitar Pedal](https://nanjingtt.wordpress.com/2023/11/13/overdrive-guitar-pedal/).

## Controls

- **Volume**, **Tone**, and **Gain** potentiometers
- A toggle switch to add **harshness / fuzz** character

## Build notes

This was my first time figuring out the mechanical dimensions and drilling an enclosure from scratch — the trickiest part of the project.
